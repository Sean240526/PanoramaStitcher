# Panorama Stitcher

基于 ORB 特征的全景图像拼接系统，支持自动排序、多图拼接，C++语言实现。

---

## 项目概述

本项目实现了一个完整的全景图像拼接流程：
- 输入多张重叠图片（支持任意顺序）
- 自动排序
- 特征提取与匹配
- 透视变换与融合
- 输出全景图

---

## 核心功能

- 自动排序：根据匹配点数自动判断图片顺序
- ORB 特征提取：高效的特征点检测与描述
- RANSAC 单应性矩阵估计：剔除误匹配，计算透视变换
- 渐变融合：消除拼接缝
- 自动裁剪黑边

---

## 编译与使用

```bash
mkdir build && cd build
cmake .. && make -j4
./stitch a.jpg b.jpg c.jpg
```

---

## 实验结果

| 测试图片分辨率 | 4640 × 2608（约 1200 万像素） |
| 拼接成功率 | 3 张真实照片全部拼接成功 |
| C++ 版耗时 | 约 7.1 秒 |
| 最终全景图尺寸 | 7089 × 2608 |
